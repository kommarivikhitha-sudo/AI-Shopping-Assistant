# AI-Shopping-Assistant

This project is an AI-powered tool designed to help users track product prices and make informed shopping decisions.

## How it works
- **Data Collection**: Uses the Anakin Universal Scraper to automatically extract real-time product information from Amazon.
- **Goal**: To simplify price monitoring and assist in better buying decisions.
